# Tampa Bay Radar

Live Florida weather radar centered on Tampa: reflectivity, velocity, precip type (rain/snow/hail),
estimated normalized rotation, NWS warnings & watches, dew point, CAPE, 24-hour climate, storm tracking
and a 60-second multi-radar mosaic. Works on desktop and as an iPhone home-screen app.

Data: NOAA/NWS (NEXRAD & TDWR via opengeo.ncep.noaa.gov, api.weather.gov), Iowa Environmental Mesonet
storm attributes, Open-Meteo. Imagery: Esri. Not an official warning source.
